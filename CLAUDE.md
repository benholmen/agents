# agents

A personal tooling repository. Work directly on `main`.

- Commit straight to `main`. Cut no branch, open no PR, and use no worktree. This line is the
  explicit instruction `rules/pr-first-contributions.md` asks for before work skips a PR.
- Push to `origin`, which is `benholmen/agents`, once the user approves the push. Never push to,
  or open a PR against, `upstream` (`jahnkelabs/agents`).
- The installed rules, skills, and agents link into this checkout, so what sits here is live in
  every session.
